# Wandbound Rules Bible Addendum: Negate a Summon

This addendum records the owner-approved timing and outcome for declared normal Character summons. It supersedes older rules only where it explicitly introduces the Pre-Summon timing point and the distinct Negate a Summon mechanic.

## Declared Summon Timing

The canonical sequence for a player-declared normal Character summon is:

```text
Declare Summon
-> Pre-Summon response window
-> Successful Summon
-> summon triggers and marker consequences
-> Post-Summon response window
```

The opponent receives first response priority in the Pre-Summon window. Existing reaction rules continue to apply: priority alternates, a legal reaction resets the pass progression, two total consecutive passes close the current window, and a player with no legal reaction automatically passes.

## Negate a Summon

Negate a Summon means: Cancel a pending summon before the unit is successfully summoned. A negated summon is not a successful summon and does not by itself destroy, sacrifice, damage, or move the attempted card to another zone.

For a normal Character declared from Hand, the exact selected card remains in Hand while the summon is pending. If the summon is negated, that card remains in Hand in its existing order unless another effect explicitly moves it.

Negate a Summon is distinct from negating an effect activation. A summon-negation reaction takes effect only if that reaction resolves successfully. If the reaction itself is negated, the pending summon remains unnegated.

## Successful Summon Boundary

When this unit is summoned applies only after the summon becomes successful. Declaration, creation of a pending summon, and opening Pre-Summon do not satisfy that condition. A negated summon never satisfies it.

After Pre-Summon closes without negation, the exact selected card and destination are revalidated. No other copy and no other tile may substitute. If revalidation fails, the summon fails without consuming the selected card or creating a unit.

## Scope

This addendum applies only to player-declared normal Character summons. It does not change Hybrid procedures, initial Hero setup, NPC or marker spawning, or summons generated by effects and triggered continuations.
