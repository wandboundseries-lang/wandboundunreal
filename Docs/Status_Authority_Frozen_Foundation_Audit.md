# Status Authority and Frozen Foundation Audit

## Scope and baseline

This public-safe audit covers the source-aware status authority and Frozen parity
implementation based on public `main` at
`f95c936a61941e58572dc698f23e9abc0a6e5bca`. Internal read-only audit material
was consulted without copying its contents into this branch. No card transfer,
Sealed gameplay, Blueprint, map, asset, Godot, Meshy,
networking, AI, or UI work is part of this change.

## Architecture

- `FWBStatusInstanceState` is the authoritative per-unit state for one canonical
  status ID, duration, and application-time provenance.
- `FWBUnitState::Statuses` and `StatusTurnsRemaining` remain deterministic
  compatibility mirrors and are normalized from typed status state.
- `WBStatusSemantics` owns narrow status-derived facts. `WBRules` remains final
  action-legality authority and `WBEffectRunner` remains mutation authority.
- Provenance records only supplied facts: application origin, source player,
  source owner snapshot, source unit, card ID, card instance ID, and effect ID.
  It does not fabricate a source unit or caster and is not rewritten when control
  changes or the source leaves play.
- Authoritative digests include provenance when it exists. Public board summaries,
  public receipts, and trace serialization do not expose private card-instance or
  source-effect identity.

## Canonical status behavior

| Status | Implemented authority |
| --- | --- |
| Burn | End-turn status damage of 1, bypassing Armor, then timed decay; normal zero-HP/death authority is reused. |
| Poison | Start-turn Max HP reduction of 1 with HP clamping and minimum Max HP 1, then timed decay; deterministic reapplication preserves the existing immediate tick. |
| Rooted | Blocks declared orthogonal and diagonal Move actions, including NPC Move legality; forced/effect relocation remains a distinct operation. |
| Stunned | Blocks source-unit Move, declared Attack, and activation; suppresses automatic character passives and Counters without disabling unrelated player-level actions. |
| Cannot Attack | Blocks declared Attack only; Move and non-attack activation remain legal, and this status alone does not suppress Counter. |
| Frozen | Blocks source-unit actions and automatic passives/Counters. A true Attack breaks Frozen on the final damage recipient and prevents that ordinary hit without consuming Armor or producing positive-HP AfterDamage. |

Canonical IDs are `Burn`, `Poison`, `Rooted`, `Stunned`, `Frozen`, and
`Cannot Attack`. Known case/spacing/underscore aliases, including `root`, `stun`,
`CannotAttack`, `cannot_attack`, `cannot attack`, and `no_attack`, converge on one
canonical state. `Negated` and unknown internal states remain distinct. Canonical-only
operations fail closed on unsupported status IDs. Sealed is recognized only as
deferred vocabulary and has no gameplay authority.

Duration `0` remains permanent. Timed reapplication uses deterministic maximum
refresh rather than stacking multiple same-status instances. Set, add, reduce,
named cleanse, and cleanse-all operate through typed state. Cleanse-all removes the
six canonical cleanseable statuses and does not erase unrelated internal state.

## Frozen attack ordering

Frozen is evaluated after pre-damage modification and damage substitution, against
the actual final recipient. A Frozen break occurs in the existing attack
continuation, removes Frozen, applies zero Armor and HP damage, preserves PostHit,
does not emit positive-HP AfterDamage, and suppresses the Counter generated by that
attack. Any successfully resolving true Attack breaks Frozen even when raw ATK is
zero. Redirected, reflected, substituted, Counter, and NPC attack paths use the
same authority; the original defender's Frozen state is not consumed when another
unit becomes the final recipient.

## Godot and compatibility audit

The read-only Godot reference establishes Burn-before-decay, Poison-at-start-turn,
one active status identity, maximum-duration refresh, Rooted declared-movement
blocking, Stunned/Frozen passive suppression, and successful-Attack Frozen break.
Godot's status tick function ignores its active-player argument; current Unreal
global boundary ticking is therefore preserved pending an explicit owner ruling.
Unreal's established permanent-duration representation remains `0` even where old
Godot data used `-1`.

Activation source gates now distinguish an omitted Frozen policy from an explicit
`blocked_by_frozen: false`. Omission fails closed; explicit false remains the
existing data-authored exception. The production bundle digest representation is
unchanged for compatibility.
